02 / USER FEEDBACK

추천은 생성됐지만, 취향은 충분히 담지 못했습니다

친구들의 실제 계정 테스트에서 보고된 정성적 관찰입니다.

01

리듬게임 선호

리듬게임 ≠ 호러게임

02

생존게임 선호

생존 취향 → 약한 반영

선호하는 생존 경험이 추천에 충분히 드러나지 않은 사례

03

낯선 게임에 대한 반응

새로운 게임 ≠ 관심

모르는 게임을 추천받았을 때 관심이 낮았던 사례

사용자 관찰 → 취향 설명과 추천 근거를 보강할 필요

사용자가 제공한 테스트 관찰입니다. 만족도·정확도·참가자 수에 대한 정량 측정값은 확보하지 않았습니다.
